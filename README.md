# Super Plumber Odyssey — Android Platformer

A native Kotlin Android platform game with custom sprite rendering, physics, sound, touch controls, save data, and handcrafted missions.

## Download

Download the latest installable **debug APK** from the repository's Releases page, or download the APK artifact from the latest GitHub Actions run.

## Build

GitHub Actions builds debug and release APK variants using JDK 17, Android SDK 34, and Gradle 8.7. The debug APK is signed with the standard Android debug key and is installable. The release APK is unsigned until a private signing key is configured.

## App details

- Application ID: `com.superplumber.odyssey`
- Minimum Android version: Android 7.0 (API 24)
- Compile / target SDK: 34
